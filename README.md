# Резюме Екатерины Леоновой: сайт для GitHub Pages

Одностраничное резюме. Сначала видна закрытая папка. По клику, касанию или клавише Enter из неё выезжает лист с резюме, а кнопка браузера «Назад» убирает его обратно. Внутри два раздела, «Резюме» и «Кейсы», и кнопки скачивания PDF и DOCX.

## Что в папке

```
index.html                         страница целиком (стили и скрипт внутри)
assets/photo.jpg                   обработанное фото
assets/cases/*.png                 скриншоты для кейсов
assets/fonts/*.woff2               шрифты (работают без Google Fonts)
assets/Leonova_Ekaterina_resume.pdf    резюме для печати и hh.ru
assets/Leonova_Ekaterina_resume.docx   резюме в Word, удобно для систем отбора
.nojekyll                          отключает обработку Jekyll на GitHub Pages
```

## Как опубликовать (10 минут, без командной строки)

1. Зайдите на github.com, нажмите **New repository**. Название, например, `leonova-cv`. Тип, **Public** (бесплатный GitHub Pages работает только для публичных репозиториев).
2. В новом репозитории: **Add file → Upload files**. Перетащите **всё содержимое** этой папки (не саму папку): `index.html`, `README.md`, `.nojekyll` и папку `assets`. Нажмите **Commit changes**.
   Файл `.nojekyll` скрытый: если он не виден в проводнике, включите показ скрытых файлов или создайте его на GitHub через **Add file → Create new file** с пустым содержимым.
3. **Settings → Pages**. В блоке *Build and deployment* выберите **Deploy from a branch**, ветка **main**, папка **/ (root)**, **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/leonova-cv/`.

Полезные ссылки для отправки:
- резюме: `https://ВАШ-ЛОГИН.github.io/leonova-cv/`
- сразу кейсы, без папки: `.../leonova-cv/#cases`
- конкретный кейс: `#case-blisters`, `#case-bonario`, `#case-line`

## После публикации

- **Превью ссылки в Telegram и мессенджерах.** В `index.html` найдите строку `<meta property="og:image" content="assets/photo.jpg">` и замените путь на полный адрес: `https://ВАШ-ЛОГИН.github.io/leonova-cv/assets/photo.jpg`.
- **Ссылку на сайт** добавьте в PDF/DOCX и в раздел «О себе» на hh.ru: «Резюме с кейсами и расчётами: …».
- На сайте видны телефон и почта, это публичная страница. Если нужно, уберите телефон, оставив Telegram.

## Как добавить новый кейс

В `index.html` найдите комментарий **«ШАБЛОН НОВОГО КЕЙСА»**. Скопируйте блок под ним (без `<!--` и `-->`), поменяйте `id`, номер, тексты и цифры. Скриншоты положите в `assets/cases/`. Затем добавьте строку в оглавление кейсов, блок `<ol class="toc">` выше по файлу, по образцу существующих строк.

Если в кейсе есть графики-полосы, ширину задаёт `style="width:XX%"`: считайте её как значение ÷ максимальное значение на графике × 100, чтобы полосы оставались в одном масштабе.
